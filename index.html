Le programme de notre carte PCB à base d'une Arduino Mega et sa réaction avec l'interface de supervision, dessinés avec les symboles normalisés ISO 5807 (NF Z 67-010) : chaque test est un losange à deux sorties Oui / Non, chaque action un rectangle.

Ce projet est protégé : seul son auteur peut le modifier. Pour l'adapter, crée ta copie, elle sera modifiable.

Symboles utilisés

  • Les lignes vont du haut vers le bas et de la gauche vers la droite. Dans tout autre sens, une flèche est obligatoire.
  • Un losange a une entrée et deux sorties, toujours étiquetées Oui et Non.
  • Un sous-programme (rectangle à double trait) renvoie à sa figure détaillée, repérée au-dessus à droite du symbole (3a à 3i).
  • Un symbole en pointillés existe dans le code mais reste désactivé dans la version actuelle.

1Programme de l'Arduino Mega

La carte est un shield enfiché sur l'Arduino Mega. Le programme commence par setup(), qui met d'abord le frein à hystérésis et les ventilateurs dans un état sûr, puis tourne en boucle dans loop() sans delay() : chaque tâche lit ou commande un élément, puis rend la main.

2Réaction carte Mega ↔ interface

Partie A, réception : la carte publie une trame toutes les 50 ms ; l'interface lit le port toutes les 20 ms et surveille la liaison toutes les 500 ms.

Partie B, transmission : la consigne de pente part de l'interface, la carte la convertit en rapport cyclique α, le demi-pont Q1 / Q2 alimente la bobine du frein, et la confirmation revient dans la trame DATA suivante.
